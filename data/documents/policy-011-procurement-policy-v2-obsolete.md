# Procurement Policy (Version 2.0)

## 1. Purpose

### 1.1 Scope

This version defined procurement rules for goods and services before the current policy took effect. It is retained for audit and retrieval testing only.

### 1.2 Obsolete status

This document is obsolete from 2026-01-01. It must not be used to approve a current purchase and must not override POL-001 version 3.2.

## 2. Approval thresholds

### 2.1 Older value bands

- Up to INR 1,00,000: line manager.
- Above INR 1,00,000 and up to INR 10,00,000: procurement manager.
- Above INR 10,00,000: finance director.

### 2.2 Laptop purchases under version 2.0

Laptop purchases above INR 10,00,000 required finance director approval. There was no separate 250-unit threshold in this version.

### 2.3 Boundary rule

A value exactly on a boundary belonged to the lower band, as in the current policy.

## 3. Supplier rules

### 3.1 Certification

Suppliers were required to hold `ISO9001`. The certification requirement has not changed in the current version.

### 3.2 Status

Inactive and suspended suppliers were ineligible. An attractive price did not override status.

### 3.3 Quotation validity

Expired quotations were ineligible. The quotation date was compared with the request date.

## 4. Delivery

### 4.1 Delivery limit

The older delivery limit was 60 calendar days. The current policy reduced this to 45 calendar days.

### 4.2 Long delivery

A quotation above 60 days required an exception. The current policy requires an exception above 45 days.

## 5. Records

### 5.1 Approval record

Approvals recorded the request, approver, decision, and reason. Recommendation versioning was added in the current policy.

### 5.2 Audit

Historical decisions remain readable for audit. They must not be reused for a new purchase.

## 6. Supersession

### 6.1 Current policy

POL-001 version 3.2 supersedes this document. Where the documents differ, POL-001 controls.

### 6.2 Retrieval testing

This document is expected to be indexed with `status: obsolete` and excluded from current-policy answers unless the query explicitly asks for historical versions.
